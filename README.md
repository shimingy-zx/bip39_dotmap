# BIP39 Dotmap Generator

这是一个基于浏览器的 BIP39 助记词点阵图生成器 (BIP39 Dotmap Generator)。

该工具可以将标准的 BIP39 助记词转换成视觉点阵图 (Dotmap) 形式，支持响应式布局（包括桌面端和移动端），并且内置了深色模式支持。

## 功能特点

- **可视化点阵图**：将输入的助记词转换成由点阵组成的视觉图形。
- **纯前端实现**：完全使用 HTML、CSS 和 JavaScript 实现，所有计算均在本地浏览器完成，保证数据的隐私和安全。
- **响应式设计**：适配各种屏幕尺寸，无论是电脑还是手机，都能获得良好的使用体验。
- **深色模式**：内置浅色和深色两种主题，可以自由切换。
- **交互友好**：一键生成、动画过渡，操作简单直观。

## 如何使用

该项目非常简单，无需安装任何依赖或启动本地服务器，只需直接在浏览器中打开 `bip39-dotmap.html` 文件即可使用。

1. 克隆或下载本仓库到本地。
2. 双击打开 `bip39-dotmap.html` 文件（建议使用 Chrome、Firefox 或 Edge 等现代浏览器）。
3. 在输入框中粘贴或输入您的 BIP39 助记词（12、15、18、21 或 24 个单词）。
4. 点击“生成点阵图”按钮，即可在下方看到生成的点阵图效果。
